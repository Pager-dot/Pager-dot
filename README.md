### 🚀 Featured projects

| Project | What it does |
|---|---|
| [**vid_translate**](https://github.com/Pager-dot/vid_translate) | Tauri desktop app for live JA/ES → EN video translation; Vosk ASR + CTranslate2 (int8-quantized MarianMT), paced-reveal captions, cross-platform CI release pipeline (AppImage/.deb/.msi) |
| [**RAG-Model**](https://github.com/Pager-dot/RAG-Model) | Multimodal document-intelligence RAG pipeline — `marker` for layout-aware PDF parsing, `qwen3-vl` for image captioning, `bge-large-en-v1.5` embeddings into ChromaDB, served locally with `gpt-oss:120b` |
| [**KIIT_WIFI_ISSUE**](https://github.com/Pager-dot/KIIT_WIFI_ISSUE) | PowerShell automation for KIIT campus WiFi login/reconnection — cut reconnection time from ~90s to ~4.5s |
| [**Screen-usage-widget**](https://github.com/Pager-dot/Screen-usage-widget) | A small desktop widget for tracking screen-time, built because nothing off-the-shelf did what I wanted |
| [**Text-Extractor-for-mac-os**](https://github.com/Pager-dot/Text-Extractor-for-mac-os) | Region-select screen OCR widget for macOS |
